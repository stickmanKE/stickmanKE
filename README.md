### 🧰 What I build with

- **Business systems**: Django POS/CRM, licensing and subscriptions (Paystack, M-Pesa), offline-first installs on Windows
- **Payments**: M-Pesa and card checkout for local businesses
- **Self-hosting**: Docker media stack (qBittorrent, VueTorrent, Sonarr, Radarr, Portainer, Homepage dashboard)
- **Networking**: reverse SSH tunnels on an Oracle VPS, Headscale VPN, custom MikroTik hotspot login portals
- **Automation**: WhatsApp chatbots and business assistant flows for service businesses
